To use this module, you need to:

1. Install the module on top of ``purchase_partner_selectable_option``.
2. Open a partner form as a user belonging to the *Purchase / Manager*
   group: the *Selectable in orders* field is displayed under the
   *Purchase* group and can be toggled.
3. Open the same partner form as a user that is not a *Purchase /
   Manager*: the *Selectable in orders* field is hidden, while the
   related purchase buttons keep behaving as defined by the parent
   module.
